# Planes

Federation is not one agent with many tools. It is several planes that cannot see each other except through ledgers.

## Hot chat

A live session in Grok, Claude, Perplexity, or another model. High residual. No authority to mutate ledgers unless David asks or a close-declaration is explicit.

Output of a hot chat is not shipped work. It is a candidate.

## Clocked agent

Grok scheduled automations on America/Chicago. They sweep connectors, close-sync, and (morning only) force one pick.

They must not open a second architecture debate. They compress and queue.

## Event agent

Narrow triggers. Current live set includes Gmail subject `AI export` and GitHub push-to-main receipts. Linear webhooks are designed, not enabled on this Grok account. Use a generic webhook receiver only after HMAC verify.

Event agents ingest or receipt. They do not rank.

## Repo agent

Copilot, GitHub Actions, capsule tests, portable-agent contracts. They act only on promoted files. They are not chat peers and they do not own Why It Matters.

## Human merge

David picks, closes, promotes, and refuses. Human declarations outrank inferred model consensus.

When two models disagree, write both residuals. Do not average them.
