# Close-sync

Offline completion is the normal path. The failure mode is a missing receipt.

## Path 2 — Linear already closed

Sweep Done and Canceled issues assigned to David, completed last 7 days.

Match an open Notion row by:

1. Source Chat URL
2. Issue identifier in the title (`TRU-6`)
3. Overlapping Key Idea

Set Notion Status Done. Empty Residual. Do not notify. Do not recreate.

Canceled and Duplicate map to Notion Done, not icebox.

## Path 1 — world-done, ledger still open

Requires an explicit human declaration that names the item or replies to a pick that named it.

Words that count: closed, resolved, already handled, that is old, I took care of it.

Then write both ledgers: Linear Done plus a one-line receipt comment, Notion Done.

Do not infer this from Gmail silence, a declined charge email, or a thread going quiet.

## Ad-hoc operator rule

If David says it in a hot chat, do the dual write immediately. Do not wait for 08:00 Chicago.

## What close-sync is not

It is not auto-close. It is not webhook-required. Linear webhooks would only speed Path 2.
