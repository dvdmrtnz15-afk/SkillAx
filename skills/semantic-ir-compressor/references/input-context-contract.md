# Input-side context contract

Codex and Grok share this page.

SkillAx is the portable discovery layer. It admits fragments. It does not own live enterprise context.

LYZT / Live Context owns retrieval, freshness, provenance, and context admission.

Organism is atlas only.

FounderLab `founderlab_mcp` is vault/handoff only.

## Law

observe ≠ authorize ≠ act

More context does not mint authority. A richer capsule does not loosen `gate_fragment`.

## Grok discovery

1. Read `semanticir://context-capsule/v1` from this MCP.
2. Compress sources you already hold into one fragment.
3. Run `gate_fragment`. Stop if rejected.
4. If live tenant context is required (fresh Linear, Slack #founder-ops, LYZT Postgres), do not scrape. Name the residual and point at LYZT.
5. Do not write Linear from a fragment.

## Freshness

Every cited fact needs `as_of` or a real URL. Silence is not current. Ad-hoc Notion/Linear/GitHub reads Grok already has are observation, not an admitted Live Context session.
