# Channels and message types

Use this file when the channel or the speech act changes the draft more than personality does.

## Channel defaults

### Email

Complete sentences. Named purpose near the top. Durable next step. Greeting and sign-off that match proximity. Assume it can be forwarded unless the user says otherwise.

### Teams or Slack

No subject-line throat clearing. Lead with the ask or the update. One screen or less unless the topic is sensitive. Thread instead of stacking context the recipient already has. Emoji only if the microculture already uses them and stakes are low.

### Text

Only with established permission or genuine time pressure. Short. One ask. No career-significant feedback by text unless the user explicitly needs a bridge to a call.

### Phone or video ask

The written note should create the conversation, not replace it. Orientation plus scheduling action. Save the sensitive payload for the live channel.

## Message types

### Delay reply

Recipient state: noticed, not dismissed. Action: the original ask, now made easy. One specific context line. No autobiography.

### First-contact or referred intro

More framing, fewer assumptions, earned warmth, complete sentences. Name the referrer if that is the trust bridge. One clear reason for writing and one easy next step.

### Upward ask

Respect plus clarity. Do not hedge the ask into invisibility. Give the decision the leader needs, options if useful, and the cost of delay. No false intimacy. No throat-clearing humility paragraph.

### Downward request or correction

Psychological safety without softening the standard out of existence. Name the behavior or need, the why, the next step, and belief that they can do it. No sarcasm. No public-shaming tone in a channel that others can see.

### Mentoring reply

Warmth without superiority. Answer the question they asked before adding extra curriculum. Offer a next conversation instead of a treatise when the stakes are career-significant.

### Candidate or interview follow-up

Career-significant, often forwardable. Encouraging without guaranteeing. Specific about process and timing. No slang. No "you crushed it" unless the sender has standing and it is true.

### Peer coordination

Brevity is respect. Action first. Context only if they lack it. Humor only if history already permits it.

### Executive-forwardable

Write as if a third reader with more power will see it. Clean structure. No jokes. No private asides. Precise ask. Names and dates. Low stiffness still allowed if the culture is modern — stiffness is not the same as rigor.

### Customer or vendor

Respect the commercial boundary. Warmth without buddy fiction. Clear owner, date, and ask. Assume the thread can be audited.

### Decline or no

Clear no, short reason if it reduces harm, alternative if one is real, relationship close that does not reopen a fake door.

### Accountability or missed commitment

Direct, specific, time-bound. No character attack. No pile of context that makes the miss look negotiable if it is not.
