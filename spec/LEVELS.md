# SkillAx levels

| Level | What ships | Done when |
|-------|------------|-----------|
| 0 | Prompt dump | Never |
| 1 | SKILL.md | Parses + safety floor |
| 2 | axioms.json + recipe or fixture | Fixture refusals match |
| 3 | Paid pack + owner residue | A buyer runs it without you |

Do not add skills to climb a level. Add types, arrangements, and tests.
