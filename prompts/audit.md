# Prompt — cognitive-load audit

Audit the following for cognitive load. Treat working memory as ~4 novel chunks.

Classify every demand as:
- Intrinsic (element interactivity required by the job)
- Extraneous (search, split attention, redundancy, ritual footer, extra skills always-on)
- Germane (effort that builds the schema — do not delete this)

Then:
1. List the interacting elements a novice must hold at once.
2. Cut extraneous first. Do not simplify by removing the job.
3. Sequence or pre-train any intrinsic load above 4 chunks.
4. Flag anything AI would offload that is actually germane (verification, constraint checks, axiom boil).
5. Redesign: always visible vs trigger vs external state.

Example input:
A README that lists 9 operating systems, a 9-section economic footer on every reply, plus the skill body for multi-agent control.

Example output (abridged):
- Intrinsic: controllability, recovery, audit, buyer context (4 — at the cap)
- Extraneous: 9 always-on OS names; repeating scorecard
- Germane: ranking control properties; naming residual risk
Cut footer and idle blurbs. Always on: TrueNorth + SkillAx. Trigger: sovereign-control-plane.
